SCENE RENDERER API REQUEST GUIDE
================================

After running:

    modal deploy scene_renderer.py

Modal prints your API URL. Replace the placeholder below with that URL.

Example base URL:

    https://YOUR-WORKSPACE--faceless-video-renderer-api.modal.run


1. SUBMIT A VIDEO RENDER
------------------------

Endpoint:

    POST https://YOUR-WORKSPACE--faceless-video-renderer-api.modal.run/render

Content-Type:

    application/json

Complete JSON request body:

{
  "credentials": {
    "DATABASE_URL": "postgresql://render_user:password@your-neon-host/neondb?sslmode=require",
    "CLOUDFLARE_R2_ACCOUNT_ID": "your-cloudflare-account-id",
    "CLOUDFLARE_R2_ACCESS_KEY_ID": "your-r2-access-key-id",
    "CLOUDFLARE_R2_SECRET_ACCESS_KEY": "your-r2-secret-access-key",
    "CLOUDFLARE_R2_BUCKET_NAME": "faceless",
    "CLOUDFLARE_R2_PUBLIC_URL": "https://pub-your-r2-domain.r2.dev",
    "CLOUDFLARE_TOKEN_": "your-cloudflare-api-token"
  },
  "KEN_BURNS_ZOOM_AMOUNT": 0.15,
  "KEN_BURNS_PAN_ZOOM": 1.10,
  "channelSlug": "example-channel",
  "topicSlug": "example-topic",
  "fps": 60,
  "width": 1376,
  "height": 768,
  "renderConcurrency": 4,
  "downloadConcurrency": 12,
  "scenes": [
    {
      "scene_number": 1,
      "imageUrl": "https://example.com/scene-1.png",
      "audioUrl": "https://example.com/scene-1.wav",
      "ken_burns": {
        "direction": "zoom-in"
      },
      "transition": "fade"
    },
    {
      "scene_number": 2,
      "imageUrl": "https://example.com/scene-2.png",
      "audioUrl": "https://example.com/scene-2.wav",
      "ken_burns": {
        "direction": "pan-right"
      },
      "transition": "fade-to-white"
    }
  ]
}


2. NODE.JS / NEXT.JS REQUEST
----------------------------

const modalUrl =
  "https://YOUR-WORKSPACE--faceless-video-renderer-api.modal.run";

const payload = {
  credentials: {
    DATABASE_URL: process.env.DATABASE_URL,
    CLOUDFLARE_R2_ACCOUNT_ID:
      process.env.CLOUDFLARE_R2_ACCOUNT_ID,
    CLOUDFLARE_R2_ACCESS_KEY_ID:
      process.env.CLOUDFLARE_R2_ACCESS_KEY_ID,
    CLOUDFLARE_R2_SECRET_ACCESS_KEY:
      process.env.CLOUDFLARE_R2_SECRET_ACCESS_KEY,
    CLOUDFLARE_R2_BUCKET_NAME:
      process.env.CLOUDFLARE_R2_BUCKET_NAME,
    CLOUDFLARE_R2_PUBLIC_URL:
      process.env.CLOUDFLARE_R2_PUBLIC_URL,
    CLOUDFLARE_TOKEN_:
      process.env.CLOUDFLARE_TOKEN_,
  },

  KEN_BURNS_ZOOM_AMOUNT: 0.15,
  KEN_BURNS_PAN_ZOOM: 1.10,

  channelSlug: "example-channel",
  topicSlug: "example-topic",

  fps: 60,
  width: 1376,
  height: 768,
  renderConcurrency: 4,
  downloadConcurrency: 12,

  scenes: [
    {
      scene_number: 1,
      imageUrl: "https://example.com/scene-1.png",
      audioUrl: "https://example.com/scene-1.wav",
      ken_burns: {
        direction: "zoom-in",
      },
      transition: "fade",
    },
  ],
};

const response = await fetch(`${modalUrl}/render`, {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
  },
  body: JSON.stringify(payload),
});

const result = await response.json();

if (!response.ok) {
  throw new Error(
    `Modal request failed (${response.status}): ${JSON.stringify(result)}`
  );
}

console.log("Submitted render:", result);


3. CURL REQUEST
---------------

First save the JSON request body as render-request.json, then run:

curl -X POST "https://YOUR-WORKSPACE--faceless-video-renderer-api.modal.run/render" \
  -H "Content-Type: application/json" \
  --data-binary @render-request.json

On Windows, use curl.exe explicitly:

curl.exe -X POST "https://YOUR-WORKSPACE--faceless-video-renderer-api.modal.run/render" ^
  -H "Content-Type: application/json" ^
  --data-binary "@render-request.json"


4. SUBMISSION RESPONSE
----------------------

The endpoint returns HTTP 202:

{
  "status": "submitted",
  "jobId": "fc-01KEXAMPLE",
  "statusPath": "/jobs/fc-01KEXAMPLE"
}

Save the returned jobId. Rendering continues in the background.


5. CHECK JOB STATUS
-------------------

Node.js:

const jobId = result.jobId;

const statusResponse = await fetch(
  `${modalUrl}/jobs/${encodeURIComponent(jobId)}`
);

const jobStatus = await statusResponse.json();
console.log(jobStatus);

Curl:

curl "https://YOUR-WORKSPACE--faceless-video-renderer-api.modal.run/jobs/fc-01KEXAMPLE"

While processing, the API returns HTTP 202:

{
  "status": "processing",
  "jobId": "fc-01KEXAMPLE"
}

When rendering finishes, it returns HTTP 200 with the generated R2 URLs:

{
  "status": "completed",
  "jobId": "fc-01KEXAMPLE",
  "result": {
    "success": true,
    "channelSlug": "example-channel",
    "topicSlug": "example-topic",
    "totalScenes": 1,
    "completedVideos": 1,
    "failedVideos": 0,
    "videos": [
      {
        "success": true,
        "sceneIndex": 1,
        "videoUrl": "https://pub-your-r2-domain.r2.dev/channels/example-channel/topics/example-topic/videos/scene-1-example.mp4",
        "publicUrl": "https://pub-your-r2-domain.r2.dev/channels/example-channel/topics/example-topic/videos/scene-1-example.mp4",
        "key": "channels/example-channel/topics/example-topic/videos/scene-1-example.mp4",
        "duration": 8.5,
        "fps": 60,
        "totalFrames": 510,
        "fileSize": 1234567
      }
    ]
  }
}


6. USING PRIVATE R2 INPUT FILES
-------------------------------

Instead of public imageUrl and audioUrl values, a scene can reference objects
inside the supplied R2 bucket:

{
  "scene_number": 1,
  "imageKey": "channels/example/topics/topic/images/scene-1.png",
  "audioKey": "channels/example/topics/topic/audio/scene-1.wav",
  "ken_burns": {
    "direction": "pan-left"
  },
  "transition": "fade"
}


7. IMPORTANT NOTES
------------------

- Send credentials only in the HTTPS POST body, never in query parameters.
- Do not call this endpoint directly from browser-side React code because that
  would expose the database and R2 credentials to users.
- Call it from a protected Next.js server route or Node.js backend.
- KEN_BURNS_ZOOM_AMOUNT is required and must be between 0.02 and 0.30.
- KEN_BURNS_PAN_ZOOM is required, greater than 1.0, and no more than 1.30.
- Every scene requires either imageUrl or imageKey.
- Every scene requires either audioUrl or audioKey.
- Missing or invalid required values return HTTP 422 without starting a render.
